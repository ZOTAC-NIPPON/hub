ZBOX PRO

MI652DX

Intel Core Ultra 5 Edge AI PC
型番 ZP-MI652DXPCP SOLUTIONS 型番 EMB-MI652DX
製造元は PCP SOLUTIONS（ZOTAC と同じ PC Partner グループの組み込みブランド）。国内では ZBOX PRO（型番 ZP-）として展開しています。

Intel Core Ultra 5 225H（Series 2）と DeepX DX-M1 NPU モジュールを組み合わせた 0.83L の x86 エッジ AI ボックス。内蔵 NPU 13 TOPS と DX-M1 25 TOPS の合計 38 TOPS を、多カメラの物体検出・安全監視・映像解析に充てます。DDR5 最大 96GB、HDMI 2.0 と DisplayPort 1.4 の 2 画面、-20〜+40℃ 対応。NPU モジュールなしのベースモデル EMB-MI652 もあります。

想定用途

多カメラの映像解析・監視映像による火災・煙の検知工場の安全監視スマートビル・入退管理外観検査・欠陥検出エッジ AI ゲートウェイ・センサーフュージョン

特長

  • Intel Core Ultra 5 プロセッサー 225H（14 コア、最大 4.9GHz、18MB キャッシュ、組み込み向けオプションあり）
  • 上位の Intel Core Ultra 7 プロセッサー 255H も選択可
  • Intel Arc Graphics（最大 2.2GHz、Intel DL Boost 対応）
  • 内蔵 Intel AI Boost NPU 13 TOPS（INT8）
  • DeepX DX-M1 M.2 NPU モジュール 25 TOPS（INT8）を M.2 2280 Key-M PCIe x4 スロットに搭載
  • DDR5-6400 SO-DIMM ×2（最大 96GB）
  • OS 用 M.2 NVMe PCIe 4.0 x4 スロット ×1（2230/2240）
  • 独立 2 画面: HDMI 2.0 ×1 ＋ DisplayPort 1.4 ×1、4K@60fps の H.265/VP9 デコード・エンコード
  • USB 3.2 Type-A ×5 ＋ USB 3.2 Type-C ×1
  • ギガビット LAN ×1
  • Intel Wi-Fi 6（802.11ax）＋ Bluetooth 5.2（オプション構成）
  • 3.5mm CTIA コンボジャック
  • CMOS バックアップ用 CR2032 電池（220mAh）
  • アクティブ冷却の金属筐体
  • 148.8×148.8×37.6 mm（0.83L）
  • 動作温度 -20〜+40℃
  • DC 19V / 65W 入力
  • CPU 側: OpenVINO・WindowsML・ONNX Runtime・DirectML・WebNN に対応
  • DeepX DX-M1 側: DXNN SDK でモデルを最適化・配備（コンパイラは x86_64 の Debian 系 Linux 向け）
  • Windows 11 と Ubuntu Linux に対応
