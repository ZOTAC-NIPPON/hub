ZBOX PRO

CM5-PICO

Raspberry Pi CM5 Palm-Size Computer
型番 ZP-CM5-PICOPCP SOLUTIONS 型番 EMB-CM5-PICO
製造元は PCP SOLUTIONS（ZOTAC と同じ PC Partner グループの組み込みブランド）。国内では ZBOX PRO（型番 ZP-）として展開しています。

Raspberry Pi Compute Module 5 を搭載した、手のひらサイズ（0.27L）のファンレス産業用 ARM コンピュータ。4K@60Hz の HDMI 2.1 を 2 系統、PTP 対応のギガビット LAN、40 ピン HAT ヘッダーと M.2 拡張を備え、本体は -20〜+55℃（同梱 AC アダプタは 0〜+40℃）で、24 時間連続運用を想定した設計です。メーカー公表の供給期間（販売継続の目安）は 2036 年 1 月まで。デジタルサイネージ・産業用 HMI・IoT ゲートウェイ・エッジ推論などの組み込み用途向けです。

特長

  • Raspberry Pi Compute Module 5（CM5）SoM。Broadcom BCM2712 クアッドコア Cortex-A76 2.4GHz
  • Broadcom VideoCore VII GPU（800MHz）。H.265/HEVC ハードウェアデコード対応
  • 独立 2 系統の 4K@60Hz HDMI 2.1 出力
  • メモリは SoM 上の LPDDR4x 2GB / 4GB / 8GB / 16GB から選択
  • ストレージは SoM 上の eMMC 16GB / 32GB / 64GB（CM5 Lite は eMMC なし・microSD スロット）
  • USB 3.2 Type-A ×2、USB Type-C ×1（ファームウェア更新用）
  • PTP 対応ギガビット LAN。Wi-Fi 5 / Bluetooth 5.0 はオプション
  • セルラー（4G CAT 1 bis）はオプション（M.2 3024 Key-B）
  • 拡張: M.2 2280 Key-M（Gen2 x1）、40 ピン GPIO HAT ヘッダー、ファンヘッダー
  • 内部カメラ／ディスプレイ用に 4 レーン DSI/CSI-2 コネクタ ×2（22 ピン）
  • 内部 RS-232 ヘッダー（RX・TX・GND）
  • 外部 I/O はすべてオンボードの TVS・ESD ダイオードで保護
  • RTC バックアップ用 CR2032 コイン電池を内蔵
  • 可動部のないパッシブ冷却のアルミ筐体
  • 動作温度 -20〜+55℃（本体）
  • DC 5〜20V のワイドレンジ入力。DC 12V 2.5A アダプタ同梱
  • メーカー公表の供給期間（販売継続の目安）は 2036 年 1 月まで
  • 工場出荷 OS は Raspberry Pi OS（Debian 13 ベース）
  • Raspberry Pi のオープンソース・エコシステム（チュートリアル・ライブラリ・HAT 製品）を活用できる
