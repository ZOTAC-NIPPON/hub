NVIDIA RTX PRO Blackwell MXM

NVIDIA RTX PRO Blackwell Generation Embedded GPU (MXM 3.1)
型番 EMB-G798 / EMB-G800 / EMB-G797
製造元は PCP SOLUTIONS（ZOTAC と同じ PC Partner グループの組み込みブランド）。ZOTAC の法人向け製品（Enterprise）として展開しています。

NVIDIA RTX PRO Blackwell 世代の GPU を MXM 3.1 モジュールにした組み込み向けグラフィックス。RTX PRO 5000（24GB）／4000（16GB）／2000（8GB）の Type B（82×110 mm）と、RTX PRO 2000（8GB）／500（6GB）の Type A（82×70 mm）の 5 モジュール。ホストとは PCIe 4.0 で接続し、映像出力は DisplayPort 2.1a（RTX PRO 5000 / 4000 は ×4、RTX PRO 2000 / 500 は ×3）と HDMI 2.1b ×1 で、各ポート最大 8K@60Hz（DSC 使用時）。メーカー公表の供給期間（販売継続の目安）は 2030 年 Q3 まで。医療・産業用の画像処理、エッジ AI 推論、サイネージなど、既存の MXM 搭載機器の GPU 更新や新規設計に向けた製品です。

特長

  • NVIDIA RTX PRO Blackwell 世代の組み込み向け GPU（第 5 世代 Tensor コア、第 4 世代 RT コア）
  • RTX PRO 5000（24GB GDDR7・256 ビット・CUDA 10,496 コア）— EMB-G798 系、Type B
  • RTX PRO 4000（16GB GDDR7・256 ビット・CUDA 7,680 コア）— EMB-G798 系、Type B
  • RTX PRO 2000（8GB GDDR7・128 ビット・CUDA 3,328 コア）— EMB-G800 系、Type B（TGP 100W）
  • RTX PRO 2000（8GB GDDR7・128 ビット・CUDA 3,328 コア）— EMB-G797 系、Type A（TGP 60W）
  • RTX PRO 500（6GB GDDR7・96 ビット・CUDA 1,792 コア）— EMB-G797 系、Type A
  • MXM 3.1 Type B は 82×110 mm、Type A は 82×70 mm
  • ホストインターフェースは PCIe 4.0（RTX PRO 5000 / 4000 は x16 / x8、RTX PRO 2000 / 500 は x8 / x4）
  • 映像出力は DisplayPort 2.1a（RTX PRO 5000 / 4000 は ×4、RTX PRO 2000 / 500 は ×3）と HDMI 2.1b。各ポート最大 7680×4320@60Hz（DSC）
  • GPU メモリの ECC に対応（RTX PRO 500 を除く）
  • NVENC（第 9 世代）／ NVDEC（第 6 世代）内蔵
  • TGP は VBIOS の既定値で出荷し、設定範囲内で変更できる（ラインアップ表を参照）
  • 動作温度 -20〜+55℃（MXM 周囲温度）
  • Windows 11 / LTSC、Ubuntu 24.04（メーカー表記は LTSC）、Linux に対応
  • メーカー公表の供給期間（販売継続の目安）は 2030 年 Q3 まで
