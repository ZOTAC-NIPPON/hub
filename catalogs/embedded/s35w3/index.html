ZBOX PRO

S35W3 / S35W3DX

Intel Core 3 Processor 304 Fanless Embedded PC
型番 ZP-S35W3 / ZP-S35W3DXPCP SOLUTIONS 型番 EMB-S35W3 / EMB-S35W3DX
製造元は PCP SOLUTIONS（ZOTAC と同じ PC Partner グループの組み込みブランド）。国内では ZBOX PRO（型番 ZP-）として展開しています。

Intel Core 3 プロセッサー 304（組み込み向け CPU）を搭載した、3.5 インチ SBC ベースの 0.82L ファンレス組み込み PC。HDMI 2.0 ×3（独立 3 画面）、RS-232/422/485 と 8 ビット GPIO の端子台、2.5GbE、DC 9〜36V 入力を備え、-20〜+45℃ での 24 時間運用を想定した設計です。内蔵 NPU で 15 TOPS、DX モデルは DeepX DX-M1 を加えて合計 40 TOPS（公称値の合算）。

特長

  • Intel Core 3 プロセッサー 304（5 コア、最大 4.3GHz、組み込み向け CPU）
  • Intel Graphics（最大 2.3GHz、GPU 演算 9 TOPS。NPU の合算値には含まない）
  • 内蔵 NPU 15 TOPS。OpenVINO・WindowsML・WebNN・ONNX Runtime に対応
  • DX モデル（ZP-S35W3DX / EMB-S35W3DX）は DeepX DX-M1 M.2 NPU モジュール（25 TOPS）を搭載
  • 独立 3 系統の HDMI 2.0 出力
  • DDR5-6400 SO-DIMM スロット ×1（最大 64GB、メモリは別途構成）
  • M.2 2280 NVMe スロット ×2（Gen4 2 レーン、SSD は別途構成）
  • RS-232 / RS-422 / RS-485 と 8 ビット GPIO を 2×9 ピン端子台で提供
  • 2.5GbE ×1
  • Intel Wi-Fi 7（802.11be）＋ Bluetooth 5.4
  • USB 3.2 Type-A ×2 ＋ USB 2.0 ×3
  • 主要 I/O を一面に集約し、配線しやすい
  • RTC バックアップ用 CR2032 電池
  • 可動部のないファンレスの金属筐体
  • 動作温度 -20〜+45℃（本体）
  • DC 9〜36V のワイドレンジ入力
  • CMOS クリアボタン、電源 LED、SSD LED
  • Windows 11 と Ubuntu Linux に対応
  • 長期供給製品（期間はお問い合わせください）
